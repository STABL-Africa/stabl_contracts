# Security

These contracts are experimental and have **not been audited**. They are
deployed to Stellar testnet only. Do not use them to hold real funds.

## Reporting a vulnerability

Please do not open a public issue for security problems. Use GitHub's private
vulnerability reporting on this repository (**Security → Report a
vulnerability**) and we will respond as quickly as we can.

Include, where possible:

- the affected contract and function
- steps or a test case that reproduces the issue
- the impact you believe it has

We will acknowledge the report, work on a fix, and credit you in the release
notes unless you prefer to remain anonymous.
